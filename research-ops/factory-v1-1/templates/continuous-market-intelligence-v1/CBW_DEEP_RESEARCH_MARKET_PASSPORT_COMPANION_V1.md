# CBW Deep Research Market Passport Companion V1

> Architecture standard mapping richer market-passport requirements into the **immutable Factory V1.1
> eleven-file Deep Research package**. Non-production. Back to
> [master system](./CBW_CONTINUOUS_EXCHANGE_MARKET_INTELLIGENCE_SYSTEM_V1.md).

## 1. Preservation guarantees

This companion **MUST NOT** change the factory. Specifically it:

- preserves the existing immutable generated `00-contract/DEEP_RESEARCH_PROMPT.md` of a task (it is
  read-only and generated by the factory; this companion never edits it);
- preserves the exact eleven-file Factory V1.1 research output and adds **no extra package files**;
- requires **no repository mutation during Deep Research** — Deep Research produces the eleven files
  in the task's `20-research-output/` only;
- requires no account testing, proxy, location spoofing or unsupported facts.

## 2. The immutable eleven-file inventory

1. `research-run.json`
2. `source-verification.json`
3. `claim-verdicts.json`
4. `conflict-resolution.json`
5. `product-availability.json`
6. `payment-rails.json`
7. `offer-eligibility-review.json`
8. `schema-normalization-notes.json`
9. `import-readiness.json`
10. `source-truth-review-report.md`
11. `MANIFEST.txt`

## 3. Requirement → file mapping

| Richer requirement | Encoded in |
| --- | --- |
| Global exchange history + country history | `research-run.json` (findings), `claim-verdicts.json` (dated claims) |
| Regulatory claims (status, license, restriction, sanction) | `claim-verdicts.json` + `source-verification.json` (tiers/snapshots) |
| KYC, products, payments, fees, limits, restrictions | `product-availability.json`, `payment-rails.json`, `claim-verdicts.json` |
| Public affiliate L1–L3 evidence | `offer-eligibility-review.json` (status, terms, "up to" language) |
| Search-intent findings + quick-answer candidates | `research-run.json` (intent notes), `source-truth-review-report.md` (answer candidates) |
| Source-monitor candidates + freshness recommendations | `source-verification.json` (sources/tiers), `schema-normalization-notes.json` (recheck notes) |
| Unresolved gaps, conflicts, limitations | `conflict-resolution.json`, `source-truth-review-report.md` |
| Architecture import mapping | `import-readiness.json` (how claims map to the canonical store) |
| Integrity/manifest of the package | `MANIFEST.txt` |

## 4. Field discipline

- Each material claim in `claim-verdicts.json` **MUST** carry confidence
  (`HIGH`/`MEDIUM`/`LOW`/`UNVERIFIED`), limitations for `LOW`/`UNVERIFIED`, effective dates and a
  source reference consistent with
  [the claim/evidence model](../../schemas/continuous-market-intelligence-v1/CBW_CLAIM_EVIDENCE_FRESHNESS_MODEL_V1.json).
- `source-verification.json` **MUST** record source tiers
  (`TIER_0_OFFICIAL` … `TIER_4_UNVERIFIED`) and snapshot references.
- `offer-eligibility-review.json` **MUST** use the affiliate verification levels and offer statuses
  from [the affiliate model](../../schemas/continuous-market-intelligence-v1/CBW_AFFILIATE_CAMPAIGN_OFFER_MODEL_V1.json)
  and **MUST NOT** contain real URLs, codes or concrete bonus amounts.
- `import-readiness.json` **MUST** describe how each claim maps to the canonical entities in
  [the data schema](../../schemas/continuous-market-intelligence-v1/CBW_MARKET_INTELLIGENCE_DATA_SCHEMA_V1.json)
  without importing anything.

## 5. Authorization floor

All authorization flags in the research package remain **false**. This companion authorizes no import,
publication, CTA, ranking, deploy or `master` action. Publication of any captured fact is gated by the
[implementation roadmap](./CBW_IMPLEMENTATION_ROADMAP_V1.md) (Phases 7–9) and
[the autonomous update policy](./CBW_AUTONOMOUS_CONTENT_UPDATE_POLICY_V1.md).

## 6. Non-goals

This companion does not run Deep Research, does not populate `20-research-output/`, and does not add,
rename or remove any of the eleven files. It is a mapping standard only.
